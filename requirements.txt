# Direct dependencies, pinned exactly.
#
# Why pins: until 2026-09-03 every line here was a `>=` floor, so each
# Render rebuild silently installed whatever was newest on PyPI. Between
# the 2026-08-27 and 2026-09-02 deploys — with no code change — the app
# moved from streamlit 1.62.0 to 1.63.0, anthropic 1.1.0 to 1.3.0 and
# psycopg 3.3.4 to 3.3.5. That makes "it worked yesterday" impossible to
# reason about and is a likely contributor to intermittent breakage.
#
# The versions below are exactly what the live 2026-09-02 build installed
# (dep-dac4u0navr4c73bep1fg), so this change is behaviour-neutral: the next
# deploy installs the same set that is running right now.
#
# constraints.txt freezes the transitive tree the same way. Bump versions
# deliberately, one at a time, and let CI run the test suite against them.
-c constraints.txt
